## 📌 Descripción del Proyecto
Este repositorio contiene el desarrollo y la organización de las actividades prácticas experimentales (**APE 4**) del segundo parcial. El proyecto está dividido estratégicamente en fases colaborativas para un desarrollo limpio y estructurado.
